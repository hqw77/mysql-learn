## 1 核心目标
从零开始配置 MySQL 环境，打通 `VS Code -> Python -> MySQL` 的完整链路，为后续的数据库开发打下基础。

## 2 环境信息
+ **操作系统**：Windows (使用 Git Bash 终端)
+ **MySQL 版本**：8.0.42 (ZIP 免安装版)
+ **安装路径**：`D:\MySQL\mysql-8.0.42-winx64\mysql-8.0.42-winx64`
+ **Python 环境**：项目级虚拟环境 `.venv`
+ **连接驱动**：`PyMySQL[rsa]`（必须带 `rsa` 额外依赖，以支持 MySQL 8.0+ 的密码加密认证）

---

## 3 关键配置步骤回顾
### 3.1配置环境变量 (必做)
ZIP 免安装版默认无法在终端直接使用 `mysql` 命令，必须把 `bin` 目录加入系统环境变量。

+ **需要加入的路径**：`D:\MySQL\mysql-8.0.42-winx64\mysql-8.0.42-winx64\bin`
+ **操作**：`Win` 键搜索“环境变量” -> 编辑系统环境变量 -> 环境变量 -> 系统变量中的 `Path` -> 新建并粘贴路径 -> 一路点“确定”。
+ **⚠️ 注意**：配置完成后必须**彻底关闭并重启 VS Code**，当前的终端才会读取到最新的环境变量。

### 3.2启动与登录 MySQL
+ 打开 VS Code 终端，输入：`mysql -u root -p`
+ 输入密码后，出现 `mysql>` 提示符，说明登录成功。
+ 退出数据库：输入 `exit;`。

![](https://cdn.nlark.com/yuque/0/2026/png/54927389/1793543935713-7e6b0148-551e-4fb8-8217-a3af12f9848f.png)

### 3.3初始化 Python 虚拟环境
在项目根目录（`mysql-learning`）的 VS Code 终端执行：

```bash
# 1. 创建虚拟环境
python -m venv .venv

# 2. 激活虚拟环境 (Git Bash 语法)
source .venv/Scripts/activate

# 3. 安装 PyMySQL 驱动
pip install "PyMySQL[rsa]"

# 4. 锁定依赖版本
pip freeze > requirements.txt
```

## 4 连通性验证代码 (`phase0/check_connection.py`)
```plain
import pymysql

try:
    conn = pymysql.connect(
        host="localhost",
        user="root",
        password="你的root密码",  # 替换为你自己的密码
        charset="utf8mb4",
    )
    print("✅ 成功连接到 MySQL 服务器！\n")

    with conn.cursor() as cur:
        cur.execute("SELECT VERSION();")
        version = cur.fetchone()
        print(f"🔹 MySQL 版本: {version[0]}\n")

        cur.execute("SHOW DATABASES;")
        print("🔹 当前系统自带的数据库:")
        for row in cur.fetchall():
            print(f"  - {row[0]}")

except pymysql.err.OperationalError as e:
    print("❌ 连接失败，请检查服务是否启动、密码是否正确")
    print(f"错误详情: {e}")
finally:
    if 'conn' in locals() and conn.open:
        conn.close()
        print("\n🔒 数据库连接已安全关闭。")
```

**验收标准**：在终端运行 `python chapters/ch01/code/phase0/check_connection.py`，能打印出 MySQL 版本号（8.0.42）和 `information_schema` 等系统库。

## 5 踩坑记录（复盘）
1. `mysql: command not found`
    - 原因：没有配置环境变量，或配置后没有重启终端。
    - 解决：将安装路径下的 `bin` 目录加入系统 `Path`。
2. `source .venv/Scripts/activate: No such file or directory`
    - 原因：还没有创建虚拟环境。
    - 解决：先执行 `python -m venv .venv`，再激活。
3. **免安装版与安装版的区别**
    - 本次使用的是 ZIP 免安装版，需要手动配环境变量、手动初始化服务。如果是 MSI 安装包，系统会自动处理这些。目前的配置已完全满足后续开发需求。
