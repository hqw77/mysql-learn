<font style="color:rgb(15, 17, 21);">告别简单的 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">id/name</font>`<font style="color:rgb(15, 17, 21);"> 表，掌握企业级建表规范，熟练选择数据类型，运用六大约束，并掌握用 Python 执行 DDL（数据定义语言）语句的方法。</font>

## <font style="color:rgb(15, 17, 21);">2. 核心理论：数据类型怎么选？</font>
### <font style="color:rgb(15, 17, 21);">2.1 数值类型</font>
+ **<font style="color:rgb(15, 17, 21);">整数</font>**<font style="color:rgb(15, 17, 21);">：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">TINYINT</font>`<font style="color:rgb(15, 17, 21);">（1字节，适合状态标记）、</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">INT</font>`<font style="color:rgb(15, 17, 21);">（4字节，常用主键）、</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">BIGINT</font>`<font style="color:rgb(15, 17, 21);">（8字节，如雪花算法ID）。</font>
+ **<font style="color:rgb(15, 17, 21);">无符号</font>**<font style="color:rgb(15, 17, 21);">：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">INT UNSIGNED</font>`<font style="color:rgb(15, 17, 21);">（表示非负数，取值范围扩大一倍）。</font>
+ **<font style="color:rgb(15, 17, 21);">⚠️</font>****<font style="color:rgb(15, 17, 21);"> 绝对避坑：金额千万别用 </font>**`**<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">FLOAT</font>**`**<font style="color:rgb(15, 17, 21);"> 或 </font>**`**<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">DOUBLE</font>**`<font style="color:rgb(15, 17, 21);">。浮点数存在精度丢失（</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">0.1 + 0.2 != 0.3</font>`<font style="color:rgb(15, 17, 21);">）。</font>
    - **<font style="color:rgb(15, 17, 21);">正确做法</font>**<font style="color:rgb(15, 17, 21);">：必须使用 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">DECIMAL(M, D)</font>`<font style="color:rgb(15, 17, 21);">。例如 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">DECIMAL(10, 2)</font>`<font style="color:rgb(15, 17, 21);"> 表示总共 10 位数字，其中小数占 2 位（最大 99999999.99）。</font>

### <font style="color:rgb(15, 17, 21);">2.2 字符串类型</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">CHAR(n)</font>`<font style="color:rgb(15, 17, 21);">：</font>**<font style="color:rgb(15, 17, 21);">定长</font>**<font style="color:rgb(15, 17, 21);">。适合长度固定的数据（如手机号 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">CHAR(11)</font>`<font style="color:rgb(15, 17, 21);">，密码MD5 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">CHAR(32)</font>`<font style="color:rgb(15, 17, 21);">）。查询极快，但不足 n 会用空格补齐。</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">VARCHAR(n)</font>`<font style="color:rgb(15, 17, 21);">：</font>**<font style="color:rgb(15, 17, 21);">变长</font>**<font style="color:rgb(15, 17, 21);">。适合长度不固定的数据（如姓名、标题、地址）。按实际长度存储，省空间。</font>
+ **<font style="color:rgb(15, 17, 21);">⚠️</font>****<font style="color:rgb(15, 17, 21);"> 建议</font>**<font style="color:rgb(15, 17, 21);">：尽量不要用 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">TEXT</font>`<font style="color:rgb(15, 17, 21);"> 存大段文本，查询极慢。大段内容（如文章正文）通常拆分到副表，或存入 NoSQL/对象存储。</font>

### <font style="color:rgb(15, 17, 21);">2.3 时间类型</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">DATETIME</font>`<font style="color:rgb(15, 17, 21);">：占 8 字节，范围 1000~9999 年，</font>**<font style="color:rgb(15, 17, 21);">不受系统时区影响</font>**<font style="color:rgb(15, 17, 21);">（存什么读什么）。适合存生日、发货时间等业务时间。</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">TIMESTAMP</font>`<font style="color:rgb(15, 17, 21);">：占 4 字节，范围 1970~2038 年，</font>**<font style="color:rgb(15, 17, 21);">受系统时区影响</font>**<font style="color:rgb(15, 17, 21);">。适合存 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">created_at</font>`<font style="color:rgb(15, 17, 21);">（创建时间）和 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">updated_at</font>`<font style="color:rgb(15, 17, 21);">（更新时间）。</font>
+ <font style="color:rgb(15, 17, 21);">魔法写法：</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">created_at DATETIME DEFAULT CURRENT_TIMESTAMP</font>`<font style="color:rgb(15, 17, 21);">（插入时自动填当前时间）；</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP</font>`<font style="color:rgb(15, 17, 21);">（修改时自动更新时间）。</font>

## <font style="color:rgb(15, 17, 21);">3. 核心理论：六大约束（给数据立规矩）</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">PRIMARY KEY</font>`<font style="color:rgb(15, 17, 21);">：主键，唯一且非空。</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">NOT NULL</font>`<font style="color:rgb(15, 17, 21);">：不能为空。</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">UNIQUE</font>`<font style="color:rgb(15, 17, 21);">：值必须唯一（如手机号、邮箱）。</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">DEFAULT</font>`<font style="color:rgb(15, 17, 21);">：默认值（如余额默认 0）。</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">CHECK</font>`<font style="color:rgb(15, 17, 21);">：检查约束（MySQL 8.0.16 之后才真正生效）。</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">FOREIGN KEY</font>`<font style="color:rgb(15, 17, 21);">：物理外键</font>**<font style="color:rgb(15, 17, 21);">（</font>****<font style="color:rgb(15, 17, 21);">⚠️</font>****<font style="color:rgb(15, 17, 21);"> 互联网大厂规范：通常禁止使用物理外键，而是在业务代码中通过逻辑保证，避免高并发下的锁竞争和分库分表麻烦）</font>**<font style="color:rgb(15, 17, 21);">。</font>

## <font style="color:rgb(15, 17, 21);">4. 表选项规范（企业级规范）</font>
<font style="color:rgb(15, 17, 21);">建表语句末尾一定要加上这些：</font>

```plain
ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='表注释';
```

+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">ENGINE=InnoDB</font>`<font style="color:rgb(15, 17, 21);">：必须选它，支持事务、行级锁、外键。</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">CHARSET=utf8mb4</font>`<font style="color:rgb(15, 17, 21);">：必须选它，支持所有字符，包括 Emoji 表情。</font>
+ `<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">COMMENT</font>`<font style="color:rgb(15, 17, 21);">：</font>**<font style="color:rgb(15, 17, 21);">极度重要</font>**<font style="color:rgb(15, 17, 21);">。给表和每一个字段都加上注释，方便团队协作。</font>

## <font style="color:rgb(15, 17, 21);">5. 实操 SQL 脚本：电商四表设计</font>
### <font style="color:rgb(15, 17, 21);">5.1 建表代码 (</font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">sql/02-create-tables.sql</font>`<font style="color:rgb(15, 17, 21);">)</font>
```plain
USE learn_mysql;

-- 1. 用户表
CREATE TABLE users (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '用户主键',
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名，唯一',
    phone CHAR(11) NOT NULL UNIQUE COMMENT '手机号，定长11位',
    balance DECIMAL(10, 2) NOT NULL DEFAULT 0.00 COMMENT '账户余额，保留两位小数',
    is_deleted TINYINT(1) NOT NULL DEFAULT 0 COMMENT '软删除标记：0正常，1已删除',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '注册时间'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';

-- 2. 商品表
CREATE TABLE products (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(100) NOT NULL COMMENT '商品标题',
    price DECIMAL(10, 2) NOT NULL COMMENT '单价',
    stock INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '库存',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='商品表';

-- 3. 订单表（主表）
CREATE TABLE orders (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    order_no VARCHAR(32) NOT NULL UNIQUE COMMENT '订单号',
    user_id INT UNSIGNED NOT NULL COMMENT '下单用户ID',
    total_amount DECIMAL(10, 2) NOT NULL COMMENT '订单总金额',
    status TINYINT NOT NULL DEFAULT 0 COMMENT '状态：0待支付，1已支付，2已发货',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单主表';

-- 4. 订单明细表（子表）
CREATE TABLE order_items (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    order_id INT UNSIGNED NOT NULL COMMENT '关联的订单ID',
    product_id INT UNSIGNED NOT NULL COMMENT '关联的商品ID',
    quantity INT UNSIGNED NOT NULL DEFAULT 1 COMMENT '购买数量',
    price DECIMAL(10, 2) NOT NULL COMMENT '购买时的单价'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单明细表';
```

## <font style="color:rgb(15, 17, 21);">6. Python 实战：执行 DDL 语句</font>
<font style="color:rgb(15, 17, 21);">在 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">practice/phase2/</font>`<font style="color:rgb(15, 17, 21);"> 下新建 </font>`<font style="color:rgb(15, 17, 21);background-color:rgb(235, 238, 242);">create_tables.py</font>`<font style="color:rgb(15, 17, 21);">：</font>

```plain
import pymysql

conn = pymysql.connect(
    host="localhost", user="root", password="你的密码",
    database="learn_mysql", charset="utf8mb4"
)

def run_ddl():
    with conn.cursor() as cur:
        create_sql = """
        CREATE TABLE IF NOT EXISTS tags (
            id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
            tag_name VARCHAR(50) NOT NULL UNIQUE COMMENT '标签名',
            created_at DATETIME DEFAULT CURRENT_TIMESTAMP
        ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
        """
        cur.execute(create_sql)
        conn.commit()  # DDL 语句也需要 commit
        print("✅ tags 表创建成功！")

        # 查看表结构 (DESC)
        cur.execute("DESC tags;")
        print("\n--- tags 表结构 ---")
        for col in cur.fetchall():
            print(col)

try:
    run_ddl()
finally:
    conn.close()
```

```plain
USE learn_mysql;

-- 先删除（注意顺序：先删子表，再删父表）
DROP TABLE IF EXISTS borrows;
DROP TABLE IF EXISTS books;
DROP TABLE IF EXISTS readers;
DROP TABLE IF EXISTS authors;

-- 1. 作者表 (authors)
CREATE TABLE authors (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '作者主键',
    name VARCHAR(50) NOT NULL COMMENT '作者姓名',
    bio TEXT COMMENT '作者简介'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='作者表';

-- 2. 图书表 (books)
CREATE TABLE books (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '图书主键',
    title VARCHAR(100) NOT NULL COMMENT '书名',
    author_id INT UNSIGNED NOT NULL COMMENT '关联作者ID',
    price DECIMAL(10, 2) NOT NULL DEFAULT 0.00 COMMENT '价格',
    publish_date DATE COMMENT '出版日期',
    stock INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '库存',
    -- 使用 CHECK 约束保证库存不为负数 (MySQL 8.0.16+ 生效)
    CONSTRAINT chk_stock CHECK (stock >= 0) 
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='图书表';

-- 3. 读者表 (readers)
CREATE TABLE readers (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '读者主键',
    name VARCHAR(50) NOT NULL COMMENT '读者姓名',
    phone CHAR(11) NOT NULL UNIQUE COMMENT '手机号，唯一约束',
    join_date DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '注册日期'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='读者表';

-- 4. 借阅记录表 (borrows)
CREATE TABLE borrows (
    id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '借阅主键',
    reader_id INT UNSIGNED NOT NULL COMMENT '关联读者ID',
    book_id INT UNSIGNED NOT NULL COMMENT '关联图书ID',
    borrow_date DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '借出时间',
    return_date DATETIME DEFAULT NULL COMMENT '归还时间，可空（NULL表示还没还）'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='借阅记录表';
```
